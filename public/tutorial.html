Tutorial & Panduan Penggunaan

Panduan lengkap langkah demi langkah menyambungkan bot WhatsApp dan mengatur AI

Menyiapkan OpenRouter API Key

Bot ini menggunakan kecerdasan buatan dari OpenRouter. Masuk ke situs OpenRouter, buat akun gratis, lalu buat API Key baru di menu pengaturan akun Anda dan tempelkan kodenya di Dashboard.

Menghubungkan WhatsApp

Buka halaman Dashboard utama. Scan QR Code yang muncul menggunakan aplikasi WhatsApp di handphone Anda (menu Perangkat Tertaut / Linked Devices) agar bot aktif dan siap membalas pesan secara otomatis.

Mengatur System Prompt / Pelatihan Bot

Tuliskan instruksi karakter bot Anda (misalnya sebagai Customer Service toko online). Anda juga bisa menggunakan tombol Auto Generate agar AI merapikan dan membuatkan pelatihan bot yang sangat detail secara otomatis.
