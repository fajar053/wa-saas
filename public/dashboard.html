Panduan Mendapatkan API Key OpenRouter

Ikuti langkah mudah di bawah ini untuk membuat API Key gratis di OpenRouter:

  1. Buka situs resmi OpenRouter
  2. Login atau buat akun baru menggunakan akun Google / GitHub kamu.
  3. Jika muncul "Legal consent" centang bagian I agree to the Terms of Service, Privacy Policy, and Model Terms. lalu "Continue"
  4. Selanjutnya Pilih "Individual" lalu Klik Next, Continue, I'll do this later dan Pilih apa aja dan klik Continue
  5. Pilih Menu API Keys atau klik (openrouter.ai/keys)
  6. Klik tombol "Create Key" di bagian kanan atas.
  7. Beri nama kunci kamu (misal: WA AutoBot AI), lalu klik Create.
  8. Salin (copy) kode kunci yang muncul (diawali dengan sk-or-v1-...).
  9. Tempelkan (paste) kode kunci tersebut ke dalam kolom OpenRouter API Key di dashboard ini.

Simpan API Key kamu dengan aman! Kunci ini hanya akan ditampilkan penuh satu kali oleh OpenRouter.
