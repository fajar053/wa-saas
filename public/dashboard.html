Panduan Mendapatkan API Key

Ikuti langkah mudah di bawah ini untuk membuat API Key:

  1. Buka situs penyedia pilihan kamu (OpenRouter atau OrcaRouter).
  2. Login atau buat akun baru menggunakan akun Anda.
  3. Masuk ke menu API Keys lalu buat key baru (*Create Key*).
  4. Salin dan tempelkan (paste) kode kunci tersebut ke kolom API Key di dashboard ini.
